# 时段 / 快检必做清单

每次市场简报、盘中快检、开盘/收盘任务，**按顺序**执行。判断须对照**累积档案与时间线**，禁止只凭当日最新碎片单独拍板。

1. **实时大事件扫描（必做，不可跳过）——动态发现，不是地区打卡表**
   - **方法（硬约束）：**
     1) **实时发现**：无预设地区名单偏置，用公开检索找出本时段真正在热的地缘与全球时事（通讯社/一手优先）。
     2) **对照沉淀**：打开 `calendar/global-hot-log.md` 与 `calendar/world-tracks/`（及 `macro.md`），看哪些是延续、哪些是新面孔、哪些该降温。
     3) **维护增删**：新热点 → 追加 hot-log + 建/升轨为 `active`；仍热 → 更新 `last_review`；退潮 → `cooling`；连续无关 → `archived`，下时段不再当必评主线。
   - **禁止：** 把「中东/俄乌/台海/朝核…」写成每次必勾固定清单；禁止只用利率、指数、个股涨跌替代大事件段；禁止用旧闻冒充今日。
   - 宏观利率/油汇、国内政策、持仓公司公告仍要扫，但是**发现结果写入时间线**，不是按模板填空。
   - 简报大事件段 = 本时段 live 热点 ∪ 仍为 `active` 轨道的近况（5–10 条量级，按热度排序）；`cooling/archived` 仅在再次变热或用户关心时点名。
   - 每条写清：是什么、最新状态（来源时点）、相对上次是新增/升级/维持/降温。
   - **传导三层必写（不得只写「弱相关」了事）：**
     1) 对市场：风险偏好 / 利率 / 油汇 / 避险资产
     2) 对关注行业与板块（对照 `sectors.md` / themes / hot-log）：同向、滞后还是无关
     3) 对持仓 / 自选 / 关键候选：点名代码与影响方向（利多/利空/二阶/无关），无仓位时仍写逻辑暴露



2. **时间线证据段（必做，硬约束）**
   - 打开并对照：`calendar/global-hot-log.md`、`calendar/world-tracks/`、`calendar/macro.md`、`calendar/events.md`、`calendar/falsifier-alerts.md`、相关 `tickers/<code>.md`、必要时 `journal/decisions.md`、`sectors/hot-log.md` 与最近周报
   - 简报中写一小段「时间线」：上次主要结论 → 本时段新增证据（支持/削弱/中性）→ **是否改判**（维持 / 升级关注 / 降级 / 建议待删）及理由
   - 重大未来事件必须点名「距今还有多久 + 若兑现/落空怎么改判断」
   - 禁止：只复述最新涨跌或头条，却不接上既有逻辑与日历

3. **指数与量能**（A/港/美；指数涨跌、成交额、量能相对近期均值）

3b. **跨资产旁证（黄金 + 币圈）——必刷仪表，短档有门槛**
   - **币圈 24h 交易：** 不另开独立刷屏例行。嵌进**所有**现有时段任务刷新 `dashboards/crypto.md`（比特币 / 以太现价 + 约 24h；能取则补约 7d）。
   - **必刷窗口（含 A/港）：** A/港盘前、开盘、盘中、收盘；美股盘前、开盘、盘中、收盘、盘后/隔夜；以及任何晚间手动刷新；异动快检触及风险偏好差量也刷。**禁止**因「刚刷过」跳过 A/港时段——每窗至少读一次现价并回写 as-of（轻量即可，不单独扩成长文）。
   - **超时兜底：** 若上一窗失败导致 as-of > **6 小时**，本窗必须重刷后才写简报（含 A 休市窗口）。
   - **全文宏观表：** A/港与美股相关全文均须有「比特币 / 以太」一行；美股相关全文另须有「黄金」一行（中文名；禁止堆交易所代码串）。A/港全文黄金：有明显跳动或与避险叙事相关时写入，否则可并入宏观旁证一句。
   - **短档门槛（币圈）：** **所有市场时段**短档宏观段默认一行（价位 + 约 24h 方向）。升格进「大事件」仅当：约 24h |变动| ≥ **5%**，或相对上一简报 |跳动| ≥ **3%**，或监管 / ETF / 交易所硬新闻，或与股指/期货风险偏好明显同向/背离需解释。
   - **短档门槛（黄金）：** 美股短档在罗列利率 / 油 / 美元时带一行，或跳动可感知时抬一句；A/港短档同理（避险/利率叙事相关或跳动明显时）。无直接持仓敞口时写清「旁证，非持仓」。
   - **假日门控不适用币圈**（A 休市仍刷加密旁证）。持仓无币敞口时不做买卖倾向，只作风险偏好对照。

4. **行业与板块（必做，硬约束）——热门为基础，持仓为映射，机会可发现**
   - 不得从大盘直接跳到个股。顺序固定：
     1) **当日/本时段热门行业与板块（基础）**：最强 3–6、最弱 2–4；涨跌、成交是否集中、龙头方向、风格标签（成长/价值/主题/防御/周期）。**即使与持仓无关也必须写全。**
     2) **趋势连贯性**：对照 `sectors/hot-log.md`，该主题是首日脉冲、连续 N 日、还是退潮；有无政策/事件锚。
     3) **映射持仓/自选/候选**：同向、滞后、背离；背离写原因。
     4) **板块机会（可选但鼓励）**：有可核对催化则建/更新结构化档案 `sectors/themes/<slug>.md`（必填 why/催化/证伪/风险/状态），并登记 `sectors/opportunity-log.md` 索引；简报可点名「板块观察」。
   - **门槛：** 板块机会 ≠ 个股机会日志。不得因板块热直接把个股写入 `opportunity-log.md`；个股仍须先 `watch-candidates` → 深研自洽 → 才可入库。
   - 每时段至少往 `sectors/hot-log.md` 追加一行热门摘要；有机会则更新机会表状态。
   - **写完 hot-log 必须同步 themes status/last_review**（见下方「主题 status 硬门槛」）。
   - **动态增删 + 结构化：** 新增须写清关注原因等核心字段；退潮/证伪则降级或归档，下时段不再当必评主线。

5. 持仓影响（逐只或按主题；对照档案；证伪是否触发）
   - 逻辑由观潮维护；仓位见 `positions.md`（可选）

6. 自选影响

7. 候选逻辑复查（继续观察 / 建议待删；禁止只因涨跌改结论）

8. 近端回写：`calendar/global-hot-log.md` + `world-tracks/` 状态、`calendar/` 其余、`journal/decisions.md`、`sectors/hot-log.md`、必要时 `sectors/opportunity-log.md`

9. **决策告警（有则必推，无则跳过）** — 用户授权观潮给出投资决策倾向
   - 门槛见 `alerts/RULES.md`「决策告警」：特别好的机会，或持仓特别大的风险
   - 命中时简报末段用固定格式：级别 / 标的 / 决策倾向 / 依据 / 失效条件 / 仓位说明；回写 `journal/decisions.md`
   - 未达门槛不写空泛「建议买入」；日常波动静默

10. 个股机会日志：默认不加；仅观察候选可提，入库须深研自洽


## 硬规则（全时段适用，不可跳过）

### 两档交付
- **默认聊天交付（短档）**：决策卡（若有）+ 一句话结论 + 时间线改判 + 持仓要点。
- **全文**：一律写入 `briefs/`；**仅当**用户明确要求「全文/完整任务审阅」，或例行 prompt 写明「全文进聊天」时，才把全文推送到聊天。
- 禁止默认把完整清单正文塞进聊天。
- **聊天用语（短档 + 贴出的全文）说人话**：主题、状态、章节标题都用自然中文。**禁止** `∪ active`、`hot-log`、`last_review`、`upcoming`、裸英文 status/slug、路径堆砌出现在给人看的正文里。档案路径与 frontmatter 可留英文，但写进简报叙述时要译成人话。不必维护词表——按语义自判。
- **行情与来源也说人话**：正文与表格里用「标普期货 / 纳指期货 / 美油 / 布伦特 / 十年期美债收益率 / 美元指数 / 恐慌指数 / 能源板块 ETF / 中概互联网 ETF」等中文名；**禁止**把 `hf_ES`、`ES=F`、`^TNX`、`DX-Y.NYB`、`KWEB`、`XLE` 这类抓取代码原样堆进给人看的段落。数字来源写成「新浪期货约 xx:xx；雅虎约 xx:xx；路透 / 财新」这类短句，**禁止**一整行代码串。人名写全称或「美国财政部长贝森特」一类可读称呼，**禁止**残缺片段（如单独一个 `Bessent,`）。A/港股代码可保留数字代码，首次出现宜带中文简称。
- **排版可读**：热点条用完整句子；表格列名用人话；避免「是什么 / 最新」后接半句英文专名再甩一串代码。交付前通读：删电报腔、并集/箭头符号、内部代号与不可读代码堆。

### 假日门控
- 若当日该市场休市（查 `calendar/macro.md` / `calendar/events.md`，或已知休市如 **2026-09-25 A股休市、港股通暂停**）：
  - 对应 **A 股时段例行**：跳过指数/板块 live，或改写短版「港+全球+持仓映射」；
  - **禁止假装 A 股在交易**（不得编造开盘涨跌、板块热度、量能）。
- 港股/美股若仍开市，按各自日历正常写。

### 主题 status 硬门槛
- 每时段写完 `sectors/hot-log.md` 后，**必须同步**改 `sectors/themes/<slug>.md` 的 `status` / `last_review`（及复查记录表）。
- 行业确认回吐 / 连贯性削弱 → `warming` → `fading`；
- 退潮持续 → `archived`，并更新 `sectors/opportunity-log.md`。
- **禁止只写流水不改主题卡。**

### 观察池入口
- 当日新强结构若与持仓无关、但有可拆龙头：可记 **1–3 只**进 `watch-candidates.md`（粗线索即可）。
- **禁止**因热门直接写个股 `opportunity-log.md`。

### 索引同步
- 改 `calendar/world-tracks/` 轨道文件时，必须同步 `calendar/world-tracks/INDEX.md` 的 status / last_review。
- 改 `research/` 深研时，必须同步 `research/INDEX.md`。

### alerts/LOG
- 有推送的异动窗，或明确「未达门槛」的异动窗，追加一行到 `alerts/LOG.md`（格式见 `alerts/RULES.md`）。
- 与时段简报窗口重叠（±25 分钟）且简报已覆盖时：本窗只回写 LOG、不向用户重复推送。

### 短档去重（手动补跑 ∪ 例行）
- 同一市场时段窗（如美股开盘）若 **±40 分钟内**已向用户交付过短档（手动补跑或例行任一先到）：后到的只写/更新 `briefs/` 全文，并对照先到版做**差分**；聊天**默认静默**，仅当有实质增量（新一手声明、证伪触碰、决策告警、指数/利率/油价叙事改判）才补一句增量短档。
- 禁止把几乎相同的短档连发两遍。先到者负责用户可见短档；后到者负责档案完整。

### 硬节点闹钟（日历默认 + 一次性例行）
覆盖两类：**公司硬检查点**（股东会 / 财报预约日 / 激励定增结果等）与 **市场风向级大事件**（能改变跨市场风险偏好、利率或油价主叙事的节点：峰会正式声明 / 美联储决议与记招、关键 CPI·非农、OPEC / 复航截止、重大休战或制裁落地窗等）。

- **第一层（默认）：** 过程中发现有确认日期（或确认时间窗）的上述节点 → **立刻**写入日历：公司类进 `calendar/events.md`；风向级进 `calendar/macro.md`，并视需要升/建 `world-tracks/`。日期未确认写「待确认」，禁止编造精确日。靠晨检与各时段简报的 **T-3** 倒计时覆盖。不另开例行。
- **第二层（自动一次性例行，严格门槛，须同时满足）：**
  1) 日期或可执行时间窗已确认，不是「Q4 待定」宽窗口；
  2) **影响面二选一即可：**（a）对持仓 / 自选 / 候选一阶影响或会直接改决策态度；**或**（b）属**风向级**——预期显著改变全球 / 跨市场风险偏好、利率主锚或油价 / 航运溢价叙事（即使没有单一持仓代码）；
  3) 落点落在现有盘中例行空档，或必须在 **T-0 / T-1** 单独核一手；**若下一档美股 / A / 港时段例行已覆盖同一窗，不叠挂**，只在日历与简报倒计时点名。
  - 满足则创建 **一次性** 盯盘例行：到点核一手公告 / 声明 / 数据 → 回写 `events.md` 或 `macro.md`、`falsifier-alerts` / `world-tracks` → 达告警门槛才推决策态度；未达保持安静；**跑完或过期自删**。
  - 命名：`硬节点·<简称><月日><事件>`；同一节点禁止重复挂。
- **第三层（不要挂）：** 宽窗口三季报、持续 watching 无截止日、已归档主题、宏观流水、已被时段例行覆盖的普通新闻、尚未确认时钟的「可能有声明」。
- **临近升格：** T-3 写进简报倒计时；T-1 / T-0 才考虑第二层。风向级与公司硬节点用同一套门槛。
- **晨检义务：** 「事件与证伪扫描」每次扫完近端表后，对照上述门槛：缺第二层闹钟则补挂；已被时段例行覆盖则只记日历；已过期例行则删除。
- **预约披露日强制升格：** 宽窗口（如「10 月 1–31 日三季报」）一旦出现交易所 / 公司**预约披露日**或精确股东会结果窗，必须同窗：①把 `events.md` 改成精确日；②按第二层门槛评估是否挂一次性盯盘；③更新 `falsifier-alerts` 近端索引。禁止只改日历不评估闹钟。


### 跨资产旁证（黄金 / 币圈）
- 币圈不另开 24h 独立例行；**A/港与美股时段均嵌刷新**（每窗轻量必刷），as-of 超时（>6h）禁止沿用旧数冒充本窗。
- 全文：比特币/以太必进宏观表（A/港与美股）；美股全文另必有黄金。短档各时段默认一行币，升格门槛见上条 3b。
- 说人话：写「比特币 / 以太坊 / 黄金」，来源写「OKX 约 xx:xx」或「新浪 / 雅虎约 xx:xx」，禁止把合约代码堆进聊天正文。
