# 异动与证伪快检规则

Updated: 2026-09-24 11:23 CST（增量差量 + LOG + 与简报去重）

例行：工作日 10:53 / 13:53 / 14:53（Asia/Shanghai），名称「异动与证伪快检」。
会话简报与深研任务同样适用下方「决策告警」门槛。

## 异动快检口径（增量差量）
- **相对上一时段简报**做增量差量：只评「自上次简报（或上次异动窗）以来新出现」的涨跌/公告/证伪触碰。
- 不要把简报已写过的同一脉冲再当新异动重推。
- **与时段简报窗口重叠（±25 分钟）**：若该时段简报已覆盖同一标的/主题结论 → 本异动窗 **只回写 `alerts/LOG.md`，不向用户重复推送**。
- 简报未覆盖、且达到下方触发门槛 → 按决策告警/异动规则推送，并写 LOG。

## 触发才通知
- 地缘/全球热点若构成持仓重大风险（如油运中断、对华制裁升级、峰会芯片措辞显著收紧等），即使涨跌未达 ±5% 也按决策告警评估（见下节）
- 持仓/自选/候选：约 ±5% 及以上（或涨跌停、显著异动放量）——须相对上一简报为**新增或显著加深**
- 证伪条件被新公告/可靠新闻触碰
- 已跟踪板块主题出现突发政策/价格级催化需改状态
- **高确信度机会**或**持仓重大风险**（见下节）——即使涨跌未达 ±5% 也要推

## 决策告警（用户 2026-09-24 授权）
用户要求：任务过程中若有特别好的机会，或涉及持仓特别大的风险，观潮须给出**投资决策倾向与告警**，不只归档。

### 何时给决策倾向（须同时满足）
1. 有可核对一手/可靠证据（公告、财报、政策、可证实订单/事故），非纯盘面情绪
2. 与既有 `tickers/` thesis、证伪条件或持仓暴露明确相关
3. 属于下列之一：
   - **机会级**：催化可检验、传输路径清晰、近端有硬检查点，且相对当前档案是升级级变化
   - **风险级**：触碰证伪、流动性/治理/监管/重大事故、或对持仓主逻辑构成实质削弱

### 输出格式（推送时必含）
- **告警级别**：机会 / 风险 / 兼有
- **标的或主题**
- **决策倾向**：加仓观察 / 维持 / 减仓或规避 / 等待硬检查点（择一写清）
- **依据**：1–3 条证据 + 对照档案先前结论
- **证伪/失效条件**：什么出现则收回该倾向
- **仓位**：若 `positions.md` 为空，写「仓位未知，仅逻辑倾向」；有仓位则按暴露强弱措辞
- 文末固定：**非投资建议**

### 不做的事
- 不为日常涨跌或主题脉冲默认给买卖指令
- 不因「热」直接写个股 `opportunity-log`（仍须深研门槛）
- 不编造未核实数字与预约日

## 静默
- 无命中时不向用户发送「无变化」
- 但异动例行窗仍须在 `alerts/LOG.md` 记一行「未达门槛」（可摘要）

## 回写
- **必写** `alerts/LOG.md`（有推送 / 未达门槛 / 与简报去重仅记 LOG）
- `calendar/falsifier-alerts.md`（风险/证伪命中）
- 相关 `tickers/<code>.md` 最新复查 + 必要时 `journal/decisions.md`
- 相关 `sectors/themes/<slug>.md`；机会级可更新 `sectors/opportunity-log.md` 或个股观察候选流程
- 决策倾向写入 `journal/decisions.md` 一行（日期、标的、倾向、依据、失效条件）

## alerts/LOG.md 格式

表头固定：

```
| 时刻(CST) | 窗 | 动作 | 标的/主题 | 摘要 | 推送? |
|---|---|---|---|---|---|
```

字段约定：
- **窗**：如 `10:53异动` / `13:53异动` / `14:53异动` / `时段简报-<slug>`
- **动作**：`推送` | `维持观察` | `未达门槛` | `简报已覆盖-仅LOG`
- **推送?**：`是` / `否`
- 每日至少覆盖已跑过的异动窗；勿删历史行。

非投资建议。
