# X 观察列表（发现层，非一手）

> **用途：** 时段简报 / 晨检的**轻量社媒发现层**。用来嗅「正在热什么」，再拿通讯社与一手交叉。  
> **禁止：** 使用操作员个人关注列表；**禁止**仅凭 X 帖升格「大事件」或触发决策告警。  
> **连接失败 / 额度不足：** 在方法段写一句跳过原因，**不阻塞**简报。  
> 账号核验：2026-09-25（API `get_users_by_usernames`）；坏链已剔除。
> **公开仓说明：** 本表为策展流程文件；导入后按本地 `portfolio.md` 补关键词，勿提交私人关注列表或实盘持仓表。

## 怎么扫（每时段窗）

1. 打开本文件；按本窗主题抽 **A 档全扫或抽 6–10 个 + B 档相关子集**（不必每次扫完全表）。
2. 取各账号**近期帖**（优先最近数小时；盘中窗可更短）。
3. 另做 **2–4 条关键词检索**（见下方词桶；与本窗热点 / 持仓相关优先）。
4. 命中 → 记为 **发现候选**（可进 `global-hot-log` 一句或简报方法段）；升格大事件仍要通讯社 / 政府·公司公告 / 交易所一手。
5. 控制费用：优先账号时间线，少做宽检索；宽检索确认额度后再跑。
